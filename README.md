# ShopRAG Genius boundary

BitGenius is a private commercial product owned in `p2ppsr/bitgenius`.
Its marketing site, customer application, API, prompts, billing, legal terms,
telemetry, product validation, and deployment source are not open source.

Reusable ShopRAG technology remains open in:

- [`shoprag/core`](https://github.com/shoprag/core) — generic ingestion orchestration;
- [`shoprag/rag-universe`](https://github.com/shoprag/rag-universe) — the generic Universe adapter;
- [`shoprag/universe`](https://github.com/shoprag/universe) — the generic vector service.

This repository is intentionally history-free and contains no BitGenius source.
It must not be used to publish or mirror the private product.
